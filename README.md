# Портфолио Маргариты Дьяченко

Статический адаптивный сайт на HTML, CSS и JavaScript. Публикация предполагается через GitHub Pages.

## Структура
- `index.html` — содержание и данные портфолио.
- `styles.css` — оформление и адаптивная сетка.
- `script.js` — мобильная навигация и текущий год.
- `documents/` — публичные подтверждения достижений (PDF).

## Как добавить подтверждения
1. Подготовьте безопасную публичную копию диплома/сертификата: закройте паспортные данные, адреса, телефоны, подписи, QR-коды с персональными данными и прочую лишнюю информацию.
2. Добавьте PDF в папку `documents/`.
3. В `index.html` замените статус «Подтверждение: PDF не добавлен» на ссылку на соответствующий файл, например `<a href="documents/award-2026.pdf" target="_blank" rel="noreferrer">Открыть подтверждение ↗</a>`.

GitHub Pages — статический хостинг. Форма загрузки, которая сохраняет файлы на сервер, здесь не реализована: новые документы добавляются в репозиторий.

## Публикация
В GitHub откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)**, нажмите **Save**. После публикации сайт будет доступен по адресу:
`https://mondrigelia.github.io/portfolio/`

## Перед публичным запуском проверьте
- точность формулировок и дат;
- ссылки на публикации и проекты;
- наличие согласия на публикацию всех материалов;
- отсутствие персональных данных в PDF.
